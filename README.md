# DigitalWaves

**DigitalWaves** est un projet web dynamique qui vise à créer une plateforme numérique complète pour la gestion de contenu et de services digitaux.  
Le projet est développé avec **PHP, MySQL, HTML, CSS, JavaScript** et utilise une structure de branches organisée (`main`, `dev`, `packages`) pour une gestion efficace du développement.

---

## 📝 Présentation du projet

- Site web offrant des services numériques avancés aux utilisateurs.  
- Gestion des comptes utilisateurs et des profils personnels.  
- Pages principales incluses : Accueil, À propos, Services, Contact.  
- Base de données MySQL pour stocker les informations de manière sécurisée et flexible.

---

## ⚙️ Prérequis

Avant de lancer le projet, assurez-vous d’avoir :

- PHP >= 8.x  
- MySQL ou MariaDB  
- Apache (XAMPP / WAMP / LAMP)  
- Navigateur moderne (Chrome, Firefox, Edge)
